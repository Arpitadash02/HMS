# HMS Frontend

React 19 + Vite + React Router.

- `npm ci` installs dependencies.
- `npm run dev` starts local development.
- `npm run build` creates `dist/`.
- Copy `.env.example` to `.env.local` and set `VITE_API_BASE_URL` if your backend is not at `http://localhost:3000`.

For production deployment instructions, see the repository-root `DEPLOYMENT.md`.
